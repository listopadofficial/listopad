# Листопад — трекер отказа от энергетиков

> Рабочее название. Первый учебный проект.

## Идея

Telegram Mini App для людей, которые хотят бросить энергетики. Классический трекер трезвости:
счётчик дней без энергетиков, рекорд, сэкономленные деньги и календарь, на котором видны
чистые дни и дни срывов. По календарю человек видит в динамике, как часто и когда он срывается.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Платформа | Telegram Mini App, без кода бота | Быстрый результат, вход уже есть через Telegram, не нужна модерация магазина |
| Режим отказа | Резко, с нуля, срыв сбрасывает серию | Самый простой и понятный механизм |
| Точность серии | В днях | Простая и однозначная логика |
| Редактирование прошлого | Дата старта может быть в прошлом, нажатие на прошедший день ставит или снимает срыв | Календарь всегда можно исправить |
| Технологии | Чистые HTML + CSS + JavaScript (ES-модули) | Учим сам язык, без сборки и фреймворков |
| Хранение | Telegram CloudStorage (в браузере — localStorage) | Не нужны сервер и база данных |
| Хостинг | GitHub Pages | Бесплатно, HTTPS, заодно учим Git/GitHub |

## Возможности версии 1

- Знакомство при первом запуске: дата старта, цена банки, банок в день
- 🔥 Текущая серия в днях
- 🏆 Рекорд — самая длинная серия
- 💰 Сэкономленные деньги
- Кнопка «Я сорвался» (с подтверждением)
- Календарь по месяцам: 🟩 чистый день, 🟥 срыв, ⬜ вне диапазона
- Настройки: изменить параметры, сбросить всё

- Живой таймер с часами и минутами
- Режим постепенного снижения (учёт банок в день)

## 1. Архитектура и файлы

```
listopad/
├── index.html    — разметка: все экраны приложения
├── style.css     — оформление
├── app.js        — точка входа: запуск, переключение экранов, кнопки
├── stats.js      — расчёты: серия, рекорд, деньги, цвет дня
├── calendar.js   — отрисовка календаря
├── storage.js    — сохранение и загрузка данных
└── tests/
    └── stats.test.js — автотесты расчётов
```

- **Логика отделена от интерфейса.** `stats.js` содержит только чистые функции: принимают данные
  и возвращают результат, ничего не знают про DOM.
- **Хранилище с подменой.** `storage.js` использует `Telegram.WebApp.CloudStorage`, если
  приложение открыто в Telegram и версия поддерживает CloudStorage (`isVersionAtLeast('6.9')`).
  Иначе он использует `localStorage`, поэтому разрабатывать можно в обычном браузере.
- **ES-модули** (`import`/`export`). Им нужен локальный сервер: `python3 -m http.server`.
- **Telegram SDK** подключается тегом
  `<script src="https://telegram.org/js/telegram-web-app.js"></script>`.

## 2. Данные и правила расчёта

### Что хранится

Один объект в формате JSON под одним ключом:

```json
{
  "startDate": "2026-11-01",
  "canPrice": 120,
  "cansPerDay": 2,
  "relapses": ["2026-11-03", "2026-11-05"]
}
```

- Даты хранятся строками `ГГГГ-ММ-ДД` по **местному** времени пользователя, чтобы обойти проблемы
  с часовыми поясами.
- В `relapses` даты не повторяются и не выходят за диапазон `[startDate, сегодня]`.
- Лимит значения в CloudStorage — 4096 символов, это около 280 дат срывов. Для версии 1 хватает.

### Что вычисляется (`stats.js`)

| Что | Правило |
|---|---|
| Цвет дня | До `startDate` или позже сегодня → ⬜. Дата есть в `relapses` → 🟥. Иначе → 🟩 |
| Текущая серия | Число 🟩 подряд, считая назад от сегодня (включительно) до последнего 🟥 или до старта. Старт сегодня → 1. Срыв сегодня → 0 |
| Рекорд | Самая длинная цепочка 🟩 подряд за всю историю |
| Сэкономлено | Все 🟩 дни × `cansPerDay` × `canPrice` |

**Главный принцип:** цифры всегда совпадают с календарём.

## 3. Экраны

### Знакомство (только когда данных нет)
- Дата старта: по умолчанию сегодня, будущую выбрать нельзя
- Цена одной банки, ₽ (> 0)
- Банок в день (целое число ≥ 1)
- Кнопка «Начать»

### Главный экран
```
        🔥 12 дней
     без энергетиков

  🏆 Рекорд: 15   💰 2 880 ₽

     [ Я сорвался ]

   ‹   Ноябрь 2026   ›
  Пн Вт Ср Чт Пт Сб Вс
  🟩 🟩 🟥 🟩 🟩 🟩 🟩
  🟩 ⬜ ⬜ ...
                    ⚙️
```
- **«Я сорвался»** спрашивает подтверждение и добавляет сегодняшнюю дату в `relapses`. Если срыв
  сегодня уже отмечен, кнопка неактивна и на ней написано «Срыв сегодня отмечен».
- **Нажатие на день** в диапазоне `[startDate, сегодня]` спрашивает подтверждение, затем ставит или
  снимает срыв.
- **Стрелки ‹ ›** листают месяцы, не раньше месяца старта и не дальше текущего.
- Неделя начинается с понедельника.

### Настройки (⚙️)
- Та же форма, что при знакомстве, но уже заполненная. Кнопка «Сохранить».
- Если дату старта сдвинули позже, срывы до новой даты удаляются.
- «Сбросить всё» (с подтверждением) удаляет данные и возвращает к экрану знакомства.

### Внешний вид
- Фон и текст берутся из темы Telegram (CSS-переменные `--tg-theme-*`), поэтому приложение
  поддерживает светлую и тёмную тему автоматически.
- Свои цвета — только у клеток 🟩 и 🟥.

## 4. Поток данных и ошибки

### Поток данных
```
Запуск:   storage.load() ──► данных нет ──► экран знакомства
                         └─► данные есть ──► render()

Действие: нажатие ──► меняем объект data ──► storage.save(data) ──► render()

render(): data ──► stats.js (числа) ──► calendar.js (клетки) ──► экран
```
Объект `data` — единственный источник правды. После любого изменения экран перерисовывается
целиком.

### Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Неверный ввод в форме | Форма не отправляется, под полем подсказка |
| Ошибка сохранения в CloudStorage | Всплывающее окно «Не удалось сохранить, попробуйте ещё раз». Данные остаются в памяти, следующее сохранение пишет объект целиком |
| Повреждённые данные (не парсятся или нет полей) | Сообщение «Данные повреждены» и предложение начать заново. Молча ничего не стираем |
| Нет CloudStorage (старый Telegram, обычный браузер) | Переключаемся на `localStorage` |

## 5. Тестирование и запуск

### Автотесты (`node --test`, без установки пакетов)
Тестируется только `stats.js`. Случаи:
- Старт сегодня, срывов нет → серия 1, рекорд 1, деньги за 1 день
- Срыв сегодня → серия 0
- Срыв в середине периода → серия после срыва, рекорд — максимальная цепочка
- Срыв в день старта
- Цвета: до старта и в будущем → ⬜
- Переход через границу месяца и февраль

Чтобы тесты не зависели от реальной даты, функции принимают «сегодня» параметром.

### Ручная проверка
Сначала в браузере на компьютере, затем в Telegram на телефоне (светлая и тёмная тема).

### Публикация
1. Разработка локально: `python3 -m http.server` → проверка в браузере
2. `git commit` + `git push` → GitHub Pages публикует на `https://<ник>.github.io/listopad/`
3. В @BotFather создать бота и привязать ссылку как мини-приложение. Код бота не нужен.
